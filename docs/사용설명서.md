# CSV Insight 사용설명서

버전 1.0 · Windows / macOS / Linux · 그림은 `docs/manual/`

수 GB~수십 GB CSV·로그를 메모리에 올리지 않고 열어서 보고, 거르고, 고치고, 내보냅니다.
설치 불필요, 외부 통신 없음, 저장 전까지 원본 불변.

---

## 1. 실행

| 방법 | |
|---|---|
| 실행 파일 | `csvinsight.exe` 더블클릭 (macOS는 `csvinsight`, 첫 실행만 우클릭 → 열기) |
| 파일 바로 열기 | CSV를 실행 파일 위로 드래그, 또는 `csvinsight.exe D:\logs\traffic.csv` |
| 파이썬 | `python3 -m csvinsight [파일]` — Python 3.9 이상, 추가 패키지 없음 |
| 스크립트 | `run.bat` (Windows) / `run.command` (macOS) |
| 종료 | 콘솔 창에서 `Ctrl+C` |

주소는 `http://127.0.0.1:<포트>/?t=<토큰>` 형식입니다. 토큰은 실행할 때마다 새로 생성되고,
토큰이 없는 요청과 `127.0.0.1`·`localhost` 이외의 호스트는 거부합니다.

## 3. 파일 열기

![파일 열기](manual/02-browse.png)

- 서버가 도는 PC의 폴더를 직접 탐색합니다. Windows는 드라이브 문자, macOS는 홈·데스크톱·다운로드·`/Volumes`가 바로가기.
- 경로를 직접 붙여넣어도 됩니다.
- 인코딩·구분자·줄바꿈·머리글 유무는 자동 판별. BOM이 있으면 그대로 따르고, 없으면 UTF-8 → CP949 → CP932 → CP1252 순.

처음 열 때만 인덱싱(진행률 표시, 취소 가능)하고, 이후에는 `<파일>.csvidx` 캐시로 즉시 열립니다.

| 파일 | 처음 열기 | 다시 열기 | 캐시 크기 |
|---|---|---|---|
| 161 MB / 200만 행 | 0.6초 | 즉시 | 15 MB |
| 1.1 GB / 1,600만 행 | 6.7초 | 즉시 | 122 MB |
| 4.7 GB / 6,000만 행 | 약 20초 | 0.7초 | 458 MB |

캐시는 행당 8바이트. 원본이 바뀌면 자동 무효화. `--no-cache`로 끌 수 있습니다.

> 열어둔 뒤 원본이 바뀌면(로그 추가·로테이션) 경고가 뜨고 저장이 막힙니다. 파일을 다시 여세요.

## 4. 검색과 필터

### 전체 검색

검색창에 입력하고 `Enter` → 모든 열을 검색해 맞는 행만 남깁니다.

![전체 검색](manual/06-quick.png)

- 옵션: **정규식**, **대소문자**, **현재 결과 내에서**(이미 걸러진 결과 안에서 재검색)
- **필터 해제**로 원복

### 열 단위 조건

**+ 조건** 버튼, 또는 셀 우클릭 → **이 값으로 필터** / **이 값 제외**.

![조건 추가](manual/07-filter.png)

| 연산 | 대상 |
|---|---|
| 포함 · 일치 · 시작 · 끝 | 문자열 |
| 정규식 | 패턴 |
| `>` `≥` `<` `≤` · 수치 범위 | 숫자 열 |
| 시간 범위 | 타임스탬프 열 |
| 목록 | `allow, deny` 중 하나 |
| 빈 값 | 빈 셀 |
| NOT | 위 전체의 반대 |

조건은 칩으로 쌓이고 모두 만족하는 행만 남습니다(AND). 칩 클릭 = 편집, × = 삭제.

### 값 분포

패널 → **값 분포** → 열 선택 → **분석**.

![값 분포](manual/08-facet.png)

- 고유값 상위 30개 + 건수 + 막대. 값을 클릭하면 그 값으로 필터.
- 숫자 열이면 최소 / 최대 / 평균 / 숫자 셀 수도 계산 (IP·날짜는 숫자로 치지 않음).

### 찾기 · 바꾸기

패널 → **찾기**.

![찾기](manual/09-find.png)

- ◀ ▶ 로 일치 지점 이동
- 모든 열 / 특정 열, 정규식, 대소문자, 셀 전체 일치, 현재 결과만
- **모두 바꾸기** — 수만 셀도 되돌리기 한 번
- **모두 책갈피** — 일치하는 행 전부 표시

## 5. 멀티 로그 서처

조건이 여러 줄인 표(방화벽 정책표 등)를 붙여넣고 한 번의 스캔으로 전부 대조합니다.
**한 줄 안의 칸들은 AND, 줄과 줄 사이는 OR.**

### 입력

패널 → **멀티 서치**. 가운데가 스프레드시트 입력칸입니다.

![조건표 붙여넣기](manual/11-rules-paste.png)

- 엑셀에서 복사한 블록을 커서 위치에 붙여넣기, 또는 직접 입력
- `Enter`·`↑`·`↓` 줄 이동, `Tab` 칸 이동, **+ 줄** / **+ 열**
- 열 너비 고정. 경계 드래그로 조절, 더블클릭으로 자동 맞춤
- 최대 2,000줄

| 값 형식 | 예 |
|---|---|
| 단일 IP | `8.8.8.8` |
| CIDR | `172.100.101.0/24`, `0.0.0.0/0` |
| 포트 / 포트 목록 | `53`, `22, 23` |
| 프로토콜 | `TCP`, `UDP`, `ICMP` |
| 문자열 포함 · 정규식 · 숫자 비교 | 드롭다운에서 선택 |

### 열 연결

각 열 머리 아래 드롭다운 = 그 조건이 로그의 어느 열과 비교되는지. 붙여넣는 즉시 자동 추측하고,
틀리면 그 자리에서 바꿉니다. 오른쪽 드롭다운은 비교 방식.

- 열 이름이 달라도 됩니다 (`src_ip` / `srcip` / `source_address` / `sa` / `출발지IP` → `Source`)
- 이름으로 판단이 안 되면 실제 값을 표본으로 판단. 머리글 없는 로그도 연결됩니다
- 열 순서 무관. `NAT Source IP`가 옆에 있어도 변환 전 열을 고릅니다
- 한 건도 안 걸리면 차선 후보로 바꿔 재대조
- 설명 열(`Purpose`, `비고`)은 조건에서 제외, 결과 이름표로만 사용
- 연결 안 된 열은 노란색. **열 자동 연결** 버튼으로 다시 추측

### 결과

**전체 검색** 실행.

![검색 결과](manual/12-rules-result.png)

- 조건별 건수가 각 줄 오른쪽 **건수** 칸에 표시. 0건은 빨간색
- 행 번호 옆 파란 배지 = 그 행을 잡은 조건 번호
- **미매칭 조건만** 체크 → 0건인 줄만
- 한 행은 위에서 처음 맞는 조건 하나에만 귀속(방화벽과 동일)

건수나 결과 줄을 클릭하면 그 조건에 맞는 행만 표시됩니다. **전체 보기**로 복귀.

![조건 하나만 보기](manual/13-rules-pick.png)

![결과 목록](manual/14-rules-summary.png)

보고 있는 결과는 **책갈피로** 표시하거나 **내보내기**로 저장할 수 있습니다.

### 속도

| | 1코어 | 3코어 |
|---|---|---|
| 1.1 GB / 1,600만 행, 정책 11줄 | 68.6초 | 25.7초 |
| 30만 행, 조건 11개 | 1.6초 | — |
| 30만 행, 조건 500개 | 1.5초 | — |

조건 수는 거의 영향이 없습니다.

## 6. 책갈피

![책갈피](manual/10-marks.png)

| 동작 | 방법 |
|---|---|
| 토글 | `M` 또는 `Ctrl`/`⌘`+`F2` |
| 이동 | `F2` 다음 / `Shift+F2` 이전 |
| 검색 결과 전체 표시 | 찾기 패널 → **모두 책갈피** |
| 같은 값 전체 표시 | 셀 우클릭 → **이 값으로 모두 책갈피** |
| 반전 / 해제 | **책갈피 반전** / **모두 해제** |
| 보기 / 내보내기 | **책갈피만 보기** / **책갈피만 내보내기** |
| 삭제 | **책갈피 행 삭제** / **책갈피 외 행 삭제** |

원본을 건드리지 않는 작업 흐름: 필터 → 모두 책갈피 → 책갈피 외 행 삭제 → 내보내기.

6천만 행 기준 60만 행 표시 0.3초, 5,940만 행 삭제 0.7초, 실행 취소 0.3초.

## 9. 저장과 내보내기

**저장** `Ctrl`+`S` — 원본 덮어쓰기, 기본으로 `.bak` 백업 생성.

**내보내기** — 다른 이름으로 저장.

![내보내기](manual/17-export.png)

| 항목 | 선택지 |
|---|---|
| 인코딩 | 원본과 동일 / UTF-8 / UTF-8(BOM 포함, Excel 권장) / CP949 / CP932 |
| 구분자 | 원본과 동일 / `,` / 탭 / `;` / `\|` |
| 줄바꿈 | 원본과 동일 / CRLF / LF |
| 범위 | 현재 필터 결과만 저장 |

- 엑셀에서 한글이 깨지면 UTF-8(BOM 포함) 또는 CP949 선택
- Windows에서 해당 파일을 엑셀이 열고 있으면 덮어쓰기 실패 — 엑셀을 닫고 재시도
- 저장은 파일 전체를 다시 쓰므로 원본 크기만큼 디스크 여유 필요(`.bak`까지면 2배)

## 10. 실행 옵션

| 옵션 | 환경변수 | 설명 |
|---|---|---|
| `--token <값>` | `CSVINSIGHT_TOKEN` | 접속 토큰 고정(최소 8자). 고정 주소로 안내할 때 |
| `--root <폴더>` | `CSVINSIGHT_ROOT` | 파일 접근을 그 폴더 안으로 제한 |
| `--port <번호>` | | 포트 고정 (기본: 임의) |
| `--no-browser` | | 브라우저 자동 실행 안 함 |
| `--no-cache` | | `.csvidx` 캐시 만들지 않음 |
| `--workers <수>` | | 필터에 쓸 프로세스 수 (`1`이면 단일) |

```bash
set CSVINSIGHT_TOKEN=정해둔값
set CSVINSIGHT_ROOT=D:\logs
csvinsight.exe
```

- 명령줄 인자는 같은 PC의 다른 사용자에게 보이므로(`ps`, 작업 관리자) 환경변수 사용 권장
- `--root`로 묶으면 그 폴더 밖은 목록에도 안 나오고, 열거나 저장할 수 없음. 상위 폴더 이동 불가, 바깥을 가리키는 심볼릭 링크도 따라가지 않음
- `--host`로 다른 주소에 바인드해도 접속은 `127.0.0.1`/`localhost`로만 허용(DNS rebinding 차단). 다른 PC에서 접속하는 용도가 아닙니다

## 11. 명령줄

```bash
csvinsight.exe info traffic.csv                       # 인코딩·구분자·행 수·열 목록
csvinsight.exe grep traffic.csv -w "Action=deny" -o deny.csv
csvinsight.exe grep traffic.csv -c "8.8.8.8" -o dns.csv    # 모든 열 부분 일치
csvinsight.exe grep traffic.csv -e "user:\d{5}"            # 정규식
csvinsight.exe convert traffic.csv -o excel.csv --encoding utf-8-sig --newline crlf
```

`-o` 생략 시 표준 출력. `--any`는 조건을 OR로 결합.

## 12. 성능과 한계

4코어 기준, 8열 로그.

| 작업 | 161 MB / 200만 행 | 4.7 GB / 6,000만 행 |
|---|---|---|
| 처음 열기 | 0.6초 | 약 20초 |
| 다시 열기 | 즉시 | 0.7초 |
| 임의 위치 200행 읽기 | 1.2 ms | 1.0 ms |
| `level = FATAL` 필터 | 0.4초 | 13초 |
| 검색 결과 모두 책갈피 | 0.01초 | 0.3초 |
| 책갈피 외 행 전부 삭제 | 0.03초 | 0.7초 |

메모리는 파일 크기와 무관하게 50 MB 내외.

**한계**

- 전체 정렬 500만 행, 중복 제거 500만 값까지
- 고정 문자열을 뽑을 수 없는 정규식(`reset|expired`, `[a-z]+`)은 전체 파싱이라 느림
- 찾기·바꾸기와 값 분포는 단일 프로세스 (필터·책갈피·멀티 서치는 병렬)
- 멀티 서치는 IPv4만 지원, 조건표 2,000줄까지
- 한 번에 한 파일 (탭·분할 보기 없음)
